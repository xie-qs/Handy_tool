# RMYYDS (Handy_tool)

一款专为 Android 开发、安全逆向分析及网络协议调试打造的高性能一站式集成工具箱。集成了 **Android Logcat 实时日志查看器**、**透明驱动级网络抓包与接口修改 (Charles / Fiddler 替代方案)**、以及 **免安装低延迟高清屏幕投屏 (Scrcpy)**。

---

## 🌟 核心功能一览

- **🌐 全功能网络抓包与接口修改 (类 Charles / Fiddler)**
  - **透明代理与驱动级拦截**：基于 WinDivert 驱动，透明重定向电脑应用（如微信小程序、各类加速器、PC 客户端）的 TCP/TLS 请求，**无感免配置系统代理**。
  - **HTTPS MITM 动态解密**：动态签发泛域名及多 SAN 证书，无缝解密 HTTPS 流量。
  - **HTTPDNS / 纯 IP 直连智能纠偏**：自动识别请求头真实 Host 域名，维护 IP ↔ 域名双向映射记忆库，支持纯 IP 嗅探解密，**彻底告别动态 IP 每次都要重新加白名单的繁琐操作**。
  - **断点拦截与参数修改**：支持请求断点、响应断点、修改 Query 参数/请求体、修改响应内容、本地直接 Mock 等高级调试功能。
  - **多进程来源精准识别**：精确标注请求来源进程（如 `💻 leigod_launcher.exe`、`📱 手机设备`），支持按来源与域名多级过滤。
  - **目标服务器真实 IP 采集**：独立展示「服务器 IP」列，支持按真实 IP 检索与一键复制。

- **📱 Android Logcat 查看器**
  - 多设备自动发现与一键热切换。
  - 支持按日志级别 (`Verbose`/`Debug`/`Info`/`Warn`/`Error`/`Fatal`) 快速着色筛选。
  - 支持按 Tag、进程名、关键词组合多维度实时过滤。
  - 智能识别日志行内的 JSON 格式数据并支持一键美化展示。

- **🖥️ 实时高清投屏 (Scrcpy 集成)**
  - 免安装内置原生 Scrcpy 工具链。
  - 毫秒级低延迟、超高清画质传输，支持鼠标点击与键盘输入操控手机。

## 🚀 快速启动与准备工作

### 1. 运行程序
- 直接双击根目录下的 [**`RMYYDS.exe`**](RMYYDS.exe) 即可。
- 程序已内置 UAC 提权清单，Windows 弹出授权提示时点击**「是」**即可（驱动级透明抓包需要管理员权限）。

### 2. 首次使用：安装根证书（仅需操作一次）
点击主界面顶部工具栏的 **「📲 安装证书」**：
- **抓电脑程序（微信小程序 / PC 客户端）**：
  点击 **「💻 一键安装证书到本机电脑」**，系统会自动将证书导入 Windows 的“受信任的根证书颁发机构”，无需手动导入证书管理器。
- **抓手机 App**：
  手机连接电脑后，点击 **「📲 一键推送证书到手机」**（或在手机浏览器中访问 `http://chls.pro/ssl` 下载并安装 CA 证书）。

## 📖 核心功能使用指南

### 一、 网络抓包与接口修改

#### 1. 抓包电脑客户端 / 微信小程序（无感免配置）
- 勾选界面顶部的 **「💻 抓电脑程序」**，点击 **「▶ 启动抓包」**。
- 底层由 WinDivert 驱动自动透明重定向网络，**无需手动修改 Windows 系统代理设置**，电脑软件、游戏加速器、微信小程序等请求均能自动捕获并解密。

#### 2. 抓手机设备 App 流量
- 确保手机和电脑连接至同一 WiFi 网络；
- 手机端设置 WiFi 代理：主机名为电脑局域网 IP，端口为 `8888`（或点击界面上的 **「📱 挂载/卸载代理」** 一键通过 ADB 自动设置）。

#### 3. 🎯 白名单机制与动态 IP 自动识别
- **真实域名优先展示**：雷神加速器等客户端采用 HTTPDNS 直连时，底层请求虽然直接连向 IP，但系统会自动解析 HTTP 报文中的真实域名（如 `geoip3.leigod.com`），界面 Host 列与左侧树状结构直接展示真实域名，物理连接 IP 归入「服务器 IP」列。
- **只需添加一次域名白名单**：
  - 在左侧域名列表或主界面请求条目上**右键** → 点击 **「🎯 设为抓包目标: *.leigod.com」**；
  - 后续该客户端无论更换多少个负载均衡 IP，系统都会自动识别其所属域名并抓包，**无需在 IP 变动时重复加白名单**。

#### 4. 🛠️ 接口修改、Mock 与断点调试
在抓包列表中选中任意接口并点击**右键**：
- **✏️ 修改请求参数**：固定替换 Query 参数或请求体，再次触发该接口时自动替换发送。
- **✏️ 修改响应内容 / 固定状态码**：固定修改服务器返回的 JSON 内容，或强制返回 200/500/403 等状态码。
- **⚡ 本地直接 Mock（不请求真实后端）**：无需经过真实源站，直接在代理层瞬间返回您配置的 Mock 数据。
- **🛑 请求 / 响应断点**：命中接口时自动暂停，弹出断点编辑窗口，支持实时逐行修改后再放行。

## ❓ 常见问题 (FAQ)

### Q1: 在 Windows 11 上可以使用吗？
**完全可以。** 软件对 Win10 / Win11 均做了深度适配（包括高 DPI 屏幕缩放自适应）。内置驱动自带合法 EV 代码签名，能正常通过 Win11 的驱动强制签名验证。若极少数电脑提示驱动无法加载，请在「Windows 安全中心 → 设备安全性」中临时关闭「内核隔离 (内存完整性)」即可。

### Q2: 为什么有的软件请求目标是 IP，抓不到包？
部分软件（如游戏加速器、特定 SDK）会绕过系统 DNS 使用 HTTPDNS 直连 IP。**`RMYYDS`** 内置纯 IP 嗅探解密机制：只要右键将该软件的根域名（如 `*.leigod.com`）加入抓包白名单，代理层会自动通过 HTTP 报文 Host 头将其识别归纳，即使换 IP 也无需重复加白名单。
